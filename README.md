# Dares E-mail 2FA

WordPress-plugin voor e-mail-2FA, uitnodigingsregistratie en accountgoedkeuring.

Download de installeerbare ZIP bij [Releases](https://github.com/spikerm/wordpress-2fa/releases). Upload die in WordPress en kies bij een update **Huidige vervangen door geüploade**.

Zie [handleiding](rex-email-2fa/LEESMIJ.md) en [validatie](rex-email-2fa/VALIDATIE.md). De pluginmap blijft `rex-email-2fa` om bestaande instellingen te behouden.

## Releases
Verhoog de pluginversie en werk RELEASE-NOTES.md bij. Een push naar main maakt via GitHub Actions een release-ZIP als die versie nog niet gepubliceerd is.
